## 📌 1. نبذة وفكرة المشروع (Project Overview)
منصة ويب إلكترونية متكاملة ومؤتمنة مخصصة لإدارة عمليات تقديم واستحواذ الطلاب الجدد في الكليات والتخصصات الجامعية المختلفة. تهدف المنصة إلى القضاء على مشكلات القبول اليدوي وحظر التضارب في المقاعد وسرعة الرد على استفسارات المتقدمين.

## 🌟 4. المميزات والخصائص الرئيسية (Core Features)

1. 🎓 **بوابة الطالب:** إنشاء حساب، التقديم الفوري، اختيار التخصص، ومتابعة حالة الطلب.
2. 👔 **لوحة تحكم موظف القبول:** تصفية الطلبات، الاعتماد أو الرفض، وتوزيع الصفحات (Pagination).
3. 🔒 **حماية المقاعد (DB Lock):** استخدام `DB::transaction` و `lockForUpdate()` لمنع تجاوز السعة الاستيعابية.
4. 📜 **سجل التتبع والتدقيق (Audit Trail):** توثيق كل حركة وتعديل على حالة الطلب بالوقت والسبب.
5. ⏰ **إدارة مواعيد القبول:** التحكم بفتح وإغلاق بوابات التقديم زمانياً.
6. 🎫 **نظام تذاكر الاستفسارات:** دعم فني ومحادثات حية بين الطالب والموظف.
7. 🔔 **جرس الإشعارات اللحظية:** إشعار الطالب فورياً عند قبول أو رفض طلبه.
8. 🌗 **الوضع الداكن والفاتح:** دعم كامل للتكيف مع مظاهر الشاشات المختلفة.
9. 📄 **التصدير والطباعة:** تصدير المقبولين لملفات CSV وطباعة تقارير رسمية.

## 🚀 5. دليل التشغيل السريع (Quick Setup Guide)

### 1️⃣ التثبيت الإعداد الأول (مرة واحدة):
```bash
# تثبيت حزم PHP و Frontend
composer install
npm install

# إنشاء وتعبئة قاعدة البيانات بالتخصصات والمستخدمين التجريبيين
php artisan migrate:fresh --seed

# بناء الملفات الأمامية
npm run build
```

### 2️⃣ التشغيل اليومي الشامل:
```bash
composer dev
```
أو عبر الأمر المباشر: `php artisan serve`  
ثم افتح الرابط في المتصفح: **`http://127.0.0.1:8000`**

### 🧪 3️⃣ تشغيل الاختبارات البرمجية الأوتوماتيكية:
```bash
php artisan test
```
*(يعود بنتيجة 29/29 Passed بنسبة 100%)*
