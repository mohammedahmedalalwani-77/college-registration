📌 1. النظرة العامة وفكرة المشروع (Project Overview & Concept)

مشروع "بوابة القبول والتسجيل الجامعي" هو منصة إلكترونية ذكية ومطورة توفر حلولاً متكاملة للطلاب الجدد وموظفي القبول والتسجيل في الجامعة. يهدف المشروع إلى أتمتة كافة مراحل تقديم طلبات التحاق الطلاب بالجامعة، وتسهيل عملية مراجعة واستحقاق المتقدمين بناءً على معدل الثانوية العامة والسعة الاستيعابية لكل تخصص.

تم بناء المنصة وفق معايير برمجية عالية تضمن عدم وقوع تعارض في المقاعد أو حجز زائد (Overbooking) بواسطة آليات حماية قواعد البيانات متزامنة التعديل (DB Transactions & LockForUpdate).

🛠️ 2. التقنيات والأدوات البرمجية المستخدمة (Tech Stack)
المجال التقنية / الحزمة الوصف والاستخدام في المشروع
اللغة الأساسية PHP 8.3+ اللغة البرمجية لتشغيل الباك إند والمعالجة المنطقية للبيانات.
إطار العمل Laravel 12.x إطار العمل الرائد لبناء المسارات، المتحكمات، النماذج، والخدمات.
تصميم الواجهات Tailwind CSS 3.4 بناء واجهات عصرية ومتجاوبة بالكامل مع الوضع الفاتح والداكن.
التفاعلات الحية Alpine.js 3.x إتاحة التفاعل السريع بالصفحة (الإشعارات، القوائم المنزلقة، والنافذة المنبثقة).
إدارة الصلاحيات Spatie Permissions إدارة أدوار وصلاحيات المستخدمين (طالب، موظف قبول، مشرف آدمن).
قاعدة البيانات SQLite / MySQL تخزين بيانات الطلاب، التخصصات، الطلبات، التذاكر، وسجل التتبع.
🌟 3. الأنظمة الفرعية والمميزات الرئيسية (Core Features)
🎓 1. بوابة الطالب التفاعلية
تمكين الطالب من إنشاء حساب جديد، التقديم الفوري، ومتابعة حالة طلبه لحظة بلحظة.
👔 2. لوحة تحكم موظف القبول
مراجعة طلبات التقديم، اتخاذ قرار القبول/الرفض، وإدارة التخصصات والسعة.
🔒 3. حماية المقاعد (DB Lock)
تأمين عملية حجز المقاعد باستخدام المعاملات المترابطة لمنع تعارض الحجز الفوري.
🔔 4. الإشعارات والتذاكر
جرس إشعارات فورية بحالة الطلب ونظام محادثات واستفسارات (Support Tickets).
